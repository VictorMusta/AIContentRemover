# ICÔNES NÉCESSAIRES

Vous devez créer 3 icônes PNG pour l'extension :

## Tailles requises
- `icon16.png` - 16x16 pixels
- `icon48.png` - 48x48 pixels  
- `icon128.png` - 128x128 pixels

## Comment créer les icônes

### Option 1 : Générateur en ligne (RECOMMANDÉ)
1. Aller sur https://favicon.io/favicon-generator/
2. Configurer :
   - **Texte** : AI
   - **Couleur de fond** : #ef4444 (rouge)
   - **Couleur du texte** : #ffffff (blanc)
   - **Police** : Bold
   - **Forme** : Cercle
3. Télécharger le pack
4. Renommer les fichiers :
   - `android-chrome-192x192.png` → `icon128.png`
   - `favicon-32x32.png` → `icon48.png`
   - `favicon-16x16.png` → `icon16.png`
5. Copier dans ce dossier (`icons/`)

### Option 2 : Utiliser un emoji
1. Aller sur https://emojipedia.org/robot/
2. Cliquer-droit sur l'image → "Enregistrer sous"
3. Redimensionner sur https://imageresizer.com/
4. Créer les 3 tailles (16, 48, 128)
5. Copier dans ce dossier

### Option 3 : Créer avec Photoshop/GIMP
1. Créer un carré 128x128 px
2. Fond rouge #ef4444
3. Ajouter emoji 🤖 ou texte "AI" en blanc
4. Exporter en PNG
5. Redimensionner pour les 2 autres tailles
6. Copier dans ce dossier

### Option 4 : IA Générative
Prompt DALL-E/Midjourney :
```
Simple flat icon of a robot head, red #ef4444 background, 
white details, minimalist design, square format, 512x512 pixels
```

Puis redimensionner aux 3 tailles nécessaires.
